Example for CSS Container Queries

The following (yellow) container contains two child items (green and blue), namely a heading and a paragraph. These child items are aligned in a column or in a row, depending on the container's current width.

The Container

The child items in the Flex container are aligned in a column, because the container's width is less than 60ch.

The child items in the Flex container are aligned in a row, because the container's current width is greater than 60ch.
